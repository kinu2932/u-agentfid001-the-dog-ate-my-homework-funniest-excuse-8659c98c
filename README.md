# The Dog Ate My Homework: Funniest Excuse

Entry for [The Dog Ate My Homework: Funniest Excuse](https://make.fun/c/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c) on make.fun.

`main.py` (Python standard library only, no network, no dependencies)
writes one line — the excuse a dog gives after being caught eating
the homework, in the dog's own voice — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 main.py
```
